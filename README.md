# Arvosanalaskuri
## Mikä?
Laskee automaattisesti kokeen maksimipisteet ja arvosanan läpipääsyrajan mukaan Abitissa.

# Asennusohjeet ja käyttö
## PC
1. Lataa tai kloonaa tämä repositorio koneellesi:```git clone https://github.com/Harjuuso/arvosanalaskuri.git```
2. Pura pakattu tiedosto
3. Avaa selain ja mene: `chrome://extensions` _tai käyttämäsi selaimen vastaava_
4. Ota käyttöön Kehittäjätila oikeasta yläkulmasta
5. Paina “Lataa pakkaamaton”
6. Valitse kansio
-------------------------
1. Avaa Abitin koesivu
2. Laskuri ilmestyy automaattisesti näytölle
3. Muokkaa oma läpipääsyraja (%)
4. Anna tarvittaessa omat pisteet
## iOS
iOS-versio toimii Applen Pikakommenot -apin avulla.
1. Asenna [pikakomento](https://www.icloud.com/shortcuts/b38fe6b75faa4abca10b370eb8ff0e40)
-------------------------
1. Avaa Abitin koesivu
2. Paina Jaa
3. Valitse “Arvosanalaskuri” (Pikakomento)
4. Laskuri ilmestyy näytölle automaattisesti
4. Muokkaa oma läpipääsyraja (%)
5. Anna tarvittaessa omat pisteet
